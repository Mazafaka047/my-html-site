# my-html-site — hand-coded web projects

Three fully hand-coded websites (HTML · CSS · JavaScript, no frameworks) built as portfolio projects. Every layout, component and interaction is written by hand — each file is a complete, self-contained site you can open and use right away.

## Projects

### 1. ZERNO — specialty coffee shop & roastery (`кофейня.html`)

Multi-page e-commerce concept in a single file: hero with brand story, menu, shop with category filters, cart & checkout flow, loyalty dashboard, blog and events. Custom CSS design system (cream/espresso/terracotta palette), branded SVG fallback illustrations if photos fail to load, mobile bottom navigation, full-screen mobile menu.

**Highlights:** cart with quantity management · category filters · sticky glass header · responsive across 6 breakpoints · CSS variables design system

### 2. SVITANOK — boutique hotel in Kyiv (`отель.html`)

Boutique hotel website: booking widget with date picking, room catalog with live pricing, services section, masonry gallery with lightbox, guest reviews slider and a personal account UI. Warm, calm visual language.

**Highlights:** booking flow · room catalog with pricing · masonry gallery + lightbox · reviews slider · account UI

### 3. FINLAD — personal finance manager (`управление финансами.html`)

Marketing landing plus a fully working app interface: dashboard with charts, transactions, budgets, goals and settings. Dark, data-dense UI with clean typography.

**Highlights:** interactive dashboard · charts · transactions & budgets · working demo state
